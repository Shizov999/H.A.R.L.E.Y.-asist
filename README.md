# H.A.R.L.E.Y.-asist
(Windows‑ассистент на Python, RU‑язык).
Возможности: Vosk/Google STT, Edge/ElevenLabs/SAPI/pyttsx3 TTS, GPT со стримингом, команды (время/дата, открытие приложений/сайтов, поиск, громкость, Википедия, анекдоты, напоминания).
Установка зависимостей (pip), подготовка Vosk‑модели.
Настройка OPENAI_API_KEY, ELEVENLABS_*, VOSK_MODEL.
Быстрый старт и примеры голосовых команд.
Структура проекта (HARLEYproject.py, папка data/).
Примечания (ориентация на Windows, интернет для онлайн‑сервисов) и идеи для развития.
